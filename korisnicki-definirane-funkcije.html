Programiranje · 2. razred · tehničar za računarstvo

Korisnički definirane funkcije

Podijeli problem na manje zadatke. Napiši funkciju jednom, pozovi je više puta.

Primjeri u C++-u

01 · Ishodi

Što ćemo naučiti?

  • Objasniti zašto program dijelimo na funkcije.
  • Prepoznati gotove i napisati vlastite funkcije.
  • Odabrati naziv, parametre i povratni tip.
  • Razlikovati deklaraciju od definicije.
  • Pozvati funkciju s ispravnim argumentima.
  • Razlikovati povratnu vrijednost od radnje tipa void.
02 · Osnovna ideja

Što je funkcija?

Funkcija je imenovani dio programa koji obavlja određeni zadatak; može primiti podatke i vratiti rezultat.

Zašto je koristimo?

  • Manje ponavljanja istog koda.
  • Jednostavnije čitanje i testiranje.
  • Složen problem postaje niz manjih zadataka.

Jednostavan prikaz

argumenti → funkcija → rezultat
  3, 4   →  zbroji  →   7

I funkcija main() funkcija je programa.

03 · Gotove funkcije

Prije vlastite: gotova funkcija

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double x = 25.0;
    cout << sqrt(x) << '\n'; // 5
    return 0;
}

sqrt(x) je unaprijed definirana funkcija iz zaglavlja <cmath>. Dobiva argument x i vraća njegov kvadratni korijen.

Pitanje: koju vrijednost ispisuje sqrt(81.0)? Odgovor: 9.

04 · Sastavni dijelovi

Potpis, parametri, rezultat

int zbroji(int a, int b) {
    return a + b;
}

int = tip povratne vrijednosti; zbroji = naziv; int a, int b = parametri.

return a + b; vraća izračunani rezultat i završava izvršavanje funkcije.

Naziv neka govori što funkcija radi; tipovi argumenata moraju odgovarati parametrima.

05 · Deklaracija i definicija

Najava ≠ izvedba

Deklaracija (prototip)

int zbroji(int a, int b);

Najavljuje naziv, povratni tip i parametre. Završava točkom sa zarezom.

Definicija

int zbroji(int a, int b) {
    return a + b;
}

Sadrži tijelo funkcije: naredbe koje se izvršavaju.

Ako je definicija prije poziva, zasebna deklaracija u jednostavnom primjeru nije potrebna. Ako je definicija poslije main(), deklariraj funkciju prije poziva.

06 · Pozivanje

Parametar nije argument

#include <iostream>
using namespace std;

int zbroji(int a, int b); // deklaracija

int main() {
    int prvi = 3, drugi = 4;
    int rezultat = zbroji(prvi, drugi); // poziv
    cout << rezultat << '\n';         // 7
    return 0;
}

int zbroji(int a, int b) { // definicija
    return a + b;
}

a i b su parametri u definiciji; prvi i drugi argumenti pri pozivu. Vrijednosti se ovdje predaju po vrijednosti.

07 · Dvije vrste

Vraća vrijednost ili obavlja radnju?

Vraća vrijednost

int kvadrat(int broj) {
    return broj * broj;
}

int x = kvadrat(5); // x = 25

Rezultat možemo spremiti ili dalje računati.

Bez povratne vrijednosti

void ispisiPozdrav() {
    cout << "Pozdrav!\n";
}

ispisiPozdrav();

void označava da funkcija ne vraća vrijednost. Poziv izvršava radnju.

08 · Razdvajanje zadatka

Jedan problem, više funkcija

Zadatak: izračunaj cijenu nakon popusta i ispiši račun.

Podjela rada

  1. izracunajPopust(cijena, postotak) vraća iznos popusta.
  2. konacnaCijena(cijena, postotak) poziva prvu funkciju i vraća novi iznos.
  3. ispisiRacun(...) ispisuje rezultat bez vraćanja vrijednosti.

Tok programa

main()
  ├─ konacnaCijena(80, 25)
  │    └─ izracunajPopust(80, 25)
  └─ ispisiRacun(80, 25, 60)

Očekivano: popust 20, konačna cijena 60.

09 · Vježba

Napiši program: popust

  1. Učitaj početnu cijenu i postotak popusta.
  2. Napiši deklaracije funkcija prije main(), a definicije poslije nje.
  3. Funkcija izracunajPopust vraća iznos popusta.
  4. Funkcija konacnaCijena poziva izracunajPopust i vraća konačnu cijenu.
  5. Funkcija ispisiRacun tipa void ispisuje podatke.

Provjeri za cijenu 80 i popust 25% → konačna cijena 60. Pretpostavi nenegativnu cijenu i postotak od 0 do 100.

#include <iostream>
#include <iomanip>
using namespace std;

double izracunajPopust(double cijena, double postotak);
double konacnaCijena(double cijena, double postotak);
void ispisiRacun(double cijena, double postotak, double ukupno);

int main() {
    double cijena, postotak;
    cout << "Cijena i popust (%): ";
    if (!(cin >> cijena >> postotak) || cijena < 0 ||
        postotak < 0 || postotak > 100) {
        cout << "Neispravan unos.\n";
        return 1;
    }
    double ukupno = konacnaCijena(cijena, postotak);
    ispisiRacun(cijena, postotak, ukupno);
    return 0;
}

double izracunajPopust(double cijena, double postotak) {
    return cijena * postotak / 100.0;
}

double konacnaCijena(double cijena, double postotak) {
    return cijena - izracunajPopust(cijena, postotak);
}

void ispisiRacun(double cijena, double postotak, double ukupno) {
    cout << fixed << setprecision(2);
    cout << "Pocetna cijena: " << cijena << '\n';
    cout << "Popust (%): " << postotak << '\n';
    cout << "Konacna cijena: " << ukupno << '\n';
}
