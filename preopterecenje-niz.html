C++ · PROGRAMIRANJE 2 · 03

Podsjetnik: kako radi funkcija?

int zbroji(int a, int b) {
    return a + b;
}

int rezultat = zbroji(3, 5); // rezultat je 8
  • int prije imena: tip povratne vrijednosti.
  • a i b: parametri u definiciji funkcije.
  • 3 i 5: argumenti u pozivu.
  • return: vraća rezultat pozivatelju.

C++ · PROGRAMIRANJE 2 · 04

Preopterećenje: isto ime, drugi parametri

Više funkcija u istom dosegu može imati isto ime ako se njihovi popisi parametara razlikuju. 

int zbroji(int a, int b) {
    return a + b;
}

double zbroji(double a, double b) {
    return a + b;
}
Prevoditelj pri prevođenju odabire odgovarajuću funkciju prema argumentima poziva. U jednostavnim primjerima tražimo potpuno podudaranje tipova.
C++ · PROGRAMIRANJE 2 · 05

Po čemu se funkcije mogu razlikovati?

Broj parametara

int zbroji(int a, int b);
int zbroji(int a, int b, int c);

Tipovi parametara

int zbroji(int a, int b);
double zbroji(double a, double b);

Redoslijed različitih tipova

void prikazi(int broj, double cijena);
void prikazi(double cijena, int broj);

 

Svaki poziv i dalje mora imati jedno najbolje podudaranje. Samo promjena imena parametra ne stvara novu funkciju.
C++ · PROGRAMIRANJE 2 · 06

Što nije preopterećenje?

int izracunaj(int x);
double izracunaj(int x); // POGREŠNO

Razlika samo u povratnom tipu nije dovoljna.

int izracunaj(int x);
int izracunaj(int broj); // ista funkcija

Različita imena parametara ne mijenjaju njihove tipove.

Zapamti: za ove funkcije promatramo ime i popis tipova parametara, a ne naziv parametra ili željeni tip rezultata.
C++ · PROGRAMIRANJE 2 · 07

Prati pozive i predvidi rezultat

int zbroji(int a, int b) { return a + b; }
double zbroji(double a, double b) { return a + b; }
int zbroji(int a, int b, int c) { return a + b + c; }

// Koja se inačica poziva?
zbroji(4, 7);
zbroji(2.5, 1.2);
zbroji(1, 2, 3);
Prikaži objašnjenje
  1. Dva parametra int → rezultat 11.
  2. Dva parametra double → rezultat 3.7.
  3. Tri parametra int → rezultat 6.
C++ · PROGRAMIRANJE 2 · 08

Zamka: dvosmislen poziv

int zbroji(int a, int b);
double zbroji(double a, double b);

zbroji(2, 3.5); // pogreška: dvosmislen poziv

Prva inačica traži pretvorbu drugog argumenta u int. Druga traži pretvorbu prvog argumenta u double. Nijedna nije bolja za oba argumenta. 

zbroji(2.0, 3.5); // jasno: double, double
Najprije razmisli želiš li računati cijelim ili decimalnim brojevima. Ne pretvaraj podatke u cijele brojeve samo da ukloniš pogrešku.
C++ · PROGRAMIRANJE 2 · 09

Vježba 1: preoptereti funkciju

Napiši dvije funkcije veci: prvu za dva cijela broja, drugu za dva decimalna broja. Svaka vraća veći broj.

// Dopuni definicije:
int veci(int a, int b) { /* ... */ }
double veci(double a, double b) { /* ... */ }

// Očekivano: 9 i 4.8
// veci(4, 9)
// veci(2.3, 4.8)
Rješenje 
int veci(int a, int b) {
    if (a > b) return a;
    return b;
}
double veci(double a, double b) {
    if (a > b) return a;
    return b;
}

C++ · PROGRAMIRANJE 2 · 11

Kako proslijediti niz?

void ispisi(const int niz[], int n) {
    for (int i = 0; i < n; i++) {
        cout << niz[i] << " ";
    }
}

// U main funkciji:
int bodovi[5] = {12, 18, 9, 20, 16};
ispisi(bodovi, 5);
  • bodovi: ime niza bez uglatih zagrada pri pozivu.
  • niz: ime parametra kojim funkcija pristupa elementima.
  • n: broj elemenata koje funkcija smije obraditi.
  • const: elementi se ne smiju mijenjati kroz taj parametar.
C++ · PROGRAMIRANJE 2 · 12

Što se zapravo prosljeđuje?

Kod ovog oblika parametra ne kopira se cijeli niz.

void obradi(int niz[], int n);
// Isti tip parametra kao:
void obradi(int* niz, int n);

Izraz koji označava niz pri ovakvom pozivu pretvara se u pokazivač na prvi element. Pokazivač se prenosi po vrijednosti, a preko njega funkcija pristupa izvornim elementima.

U ovoj lekciji koristimo školski oblik tip niz[], int n. Broj elemenata predajemo zasebno.

Veza: bodovi → prvi element → niz[0], niz[1], …

C++ · PROGRAMIRANJE 2 · 13

Primjer: zbroj svih elemenata

int zbrojNiza(const int niz[], int n) {
    int zbroj = 0;
    for (int i = 0; i < n; i++) {
        zbroj += niz[i];
    }
    return zbroj;
}

int bodovi[5] = {12, 18, 9, 20, 16};
int ukupno = zbrojNiza(bodovi, 5); // 75
Funkcija: n je nenegativan i ne prelazi broj dostupnih elemenata, zbroj mora stati u tip int. Za n = 0 petlja se ne izvršava, a rezultat je 0.
C++ · PROGRAMIRANJE 2 · 14

Prati zbroj korak po korak

Simulacija petlje za niz {12, 18, 9, 20, 16}. Ovo je prikaz algoritma u pregledniku, a ne izvršavanje C++ koda.

zbroj = 0;
for (int i = 0; i < n; i++) {
    zbroj += niz[i];
}
C++ · PROGRAMIRANJE 2 · 15

Promjena elemenata mijenja izvorni niz

void povecaj(int niz[], int n) {
    for (int i = 0; i < n; i++) {
        niz[i] += 1;
    }
}

int brojevi[3] = {2, 4, 6};
povecaj(brojevi, 3);
// brojevi sada sadrži {3, 5, 7}
Bez const funkcija može mijenjati izvorne elemente. S const parametrom pokušaj niz[i] += 1; bio bi pogreška pri prevođenju.

Usporedi: promjena lokalnog parametra n ne mijenja varijablu predanu kao broj elemenata.

C++ · PROGRAMIRANJE 2 · 16

Tri česte pogreške s nizovima

  1. Izlazak izvan granica

    i <= n je pogrešno za obradu n elemenata. Koristi i < n.

  2. Pogrešan broj elemenata

    Poziv s većim brojem od dostupnih elemenata može dovesti do nedefiniranog ponašanja. Nema automatske provjere granica.

  3. Traženje duljine pomoću sizeof unutar funkcije

    U parametru int niz[] tip se prilagođava u int* sizeof(niz) zato daje veličinu pokazivača, ne izvornog niza.
Ni zapis void f(int niz[5]) ne nameće duljinu 5 niti stvara preopterećenje različito od void f(int niz[10]).
C++ · PROGRAMIRANJE 2 · 17

Povežimo teme: ispis različitih nizova

void ispisi(const int niz[], int n) {
    for (int i = 0; i < n; i++)
        cout << niz[i] << " ";
        cout << '\n';
}

void ispisi(const double niz[], int n) {
    for (int i = 0; i < n; i++)
        cout << niz[i] << " ";
        cout << '\n';
}
Ime i broj parametara su isti, ali se razlikuje tip elemenata niza: const int* nasuprot const double*. To je valjano preopterećenje.

C++ · PROGRAMIRANJE 2 · 19

Vježba 2: analiziraj rezultate

Napiši funkciju koja vraća broj elemenata niza većih od zadane granice.

int brojVecih(const int niz[], int n, int granica);

// Za {10, 15, 18, 20} i granicu 15 rezultat je 2.
// Usporedba je strogo >, a ne >=.
Rješenje 
int brojVecih(const int niz[], int n, int granica) {
    int broj = 0;
    for (int i = 0; i < n; i++) {
        if (niz[i] > granica) broj++;
    }
    return broj;
}
Provjeri tri slučaja: nijedan element nije veći, svi su veći i neki su jednaki granici. Pretpostavka: 0 ≤ n ≤ broj dostupnih elemenata.
C++ · PROGRAMIRANJE 2 · 20

Samostalni rad: dvije inačice, isto ime

  1. Napiši prebrojiPozitivne(const int niz[], int n).
  2. Preoptereti je za niz tipa double.
  3. U main pozovi obje inačice.
  4. Objasni zašto je const dobar izbor.
int a[5] = {-2, 0, 5, 8, -1};       // rezultat: 2
double b[4] = {0.5, -1.2, 0.0, 3.4}; // rezultat: 2
Rješenje funkcija 
int prebrojiPozitivne(const int niz[], int n) {
    int broj = 0;
    for (int i = 0; i < n; i++)
        if (niz[i] > 0) broj++;
    return broj;
}
int prebrojiPozitivne(const double niz[], int n) {
    int broj = 0;
    for (int i = 0; i < n; i++)
        if (niz[i] > 0) broj++;
    return broj;
}

C++ · PROGRAMIRANJE 2 · 22

Sažetak

  • Preopterećenje znači isto ime funkcije, ali različite popise parametara.
  • Samo drukčiji povratni tip nije dovoljan.
  • Prevoditelj bira najbolje podudaranje, dvosmislen poziv je pogreška.
  • U obliku tip niz[] parametar se prilagođava pokazivaču.
  • Broj dostupnih elemenata predajemo zasebnim parametrom.
  • Bez const funkcija može promijeniti izvorne elemente.
  • Za obradu n elemenata koristimo indekse od 0 do n − 1.
Napiši valjan par preopterećenih funkcija i jedan poziv funkcije kojoj predaješ niz. Objasni u jednoj rečenici zašto predaješ i broj elemenata.
