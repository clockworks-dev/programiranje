1 · Osnovni tipovi podataka

Tip opisuje vrstu vrijednosti u memoriji

Pri deklaraciji varijable u C++-u određujemo kakav podatak varijabla može sadržavati. Pravilan tip olakšava računanje i sprječava pogreške.

TipPrimjerUpotreba
intint brojUcenika = 26;Cijeli brojevi.
doubledouble napon = 230.0;Realni brojevi, veća preciznost.
floatfloat temp = 21.5f;Realni brojevi, obično manja preciznost od double.
charchar razred = 'B';Jedan znak, piše se jednostrukim navodnicima.
boolbool prijavljen = true;Logička vrijednost: true ili false.
std::stringstd::string ime = "Ana";Tekst; zahtijeva zaglavlje <string>.
Tipovi bool, cjelobrojni tipovi, tipovi znakova i tipovi s pomičnim zarezom pripadaju temeljnim tipovima C++-a. std::string je tip iz standardne biblioteke.
1 · Odabir tipa

Odaberi tip prema značenju podatka

Primjer mjerenja

int brojSenzora = 4;
double temperatura = 23.75;
bool alarmAktivan = false;
char oznakaZone = 'A';

Broj senzora nema decimalni dio, dok temperatura može imati.

Pazi na cjelobrojno dijeljenje

int a = 5;
int b = 2;
int rezultat1 = a / b;        // 2

double rezultat2 = 5.0 / 2;  // 2.5

Izraz s dva int operanda daje cjelobrojni rezultat. Dovoljno je da barem jedan operand bude realan kako bi rezultat mogao sadržavati decimalni dio.

brojač → intmjerenje → doubleda/ne → booljedan znak → chartekst → std::string
2 · Konstante

const štiti vrijednost od izmjene

Konstanta se inicijalizira pri deklaraciji. Nakon toga joj se vrijednost ne smije mijenjati.

Primjer

const double PDV = 0.25;
const int MAKS_BODOVA = 100;

double cijena = 80.0;
double sPdv = cijena * (1 + PDV);

Zašto je to dobra praksa?

  • Ime konstante objašnjava značenje vrijednosti.
  • Kompajler sprječava slučajnu izmjenu.
  • Izbjegavaju se „magični brojevi” u kodu.
  • Promjena pravila radi se na jednom mjestu.
const int MAX_POKUSAJA = 3;
// MAX_POKUSAJA = 5;  // pogreška: const vrijednost se ne može mijenjati
Nazivi konstanti često se pišu velikim slovima radi lakšeg prepoznavanja, ali to je dogovor programera — ključna riječ koja štiti vrijednost jest const.
3 · Standardne biblioteke

Provjereni alati koji dolaze uz C++

Standardna biblioteka nudi zaglavlja, funkcije i klase za česte zadatke. Uključujemo ih naredbom #include.

<iostream>

Ulaz i izlaz: std::cin, std::cout.

<cmath>

Matematika: std::sqrt, std::pow, std::abs.

<algorithm>

Algoritmi: std::max, std::min, std::sort.

<string>

Tekstualni tip std::string.

<iomanip>

Oblikovanje ispisa: std::fixed, std::setprecision.

<vector>

Dinamički niz: std::vector.

3 · Korištenje biblioteke

#include, std:: i funkcija

Jasan način

#include <iostream>
#include <cmath>

int main() {
    double korijen = std::sqrt(81.0);
    std::cout << korijen;
}

std:: pokazuje da ime dolazi iz standardnog prostora imena.

Što provjeriti?

  • Je li uključeno odgovarajuće zaglavlje?
  • Prima li funkcija odgovarajući tip argumenta?
  • Koji tip funkcija vraća?
  • Jesu li rubni slučajevi ispravni, npr. korijen negativnog broja?
Standardna biblioteka obuhvaća mnogo više od ispisa: kontejnere, algoritme, rad s tekstom, matematičke funkcije, datoteke i druge alate.
4 · Redoslijed operanada

Prioritet operatora određuje grupiranje izraza

Prioritet

int x = 2 + 3 * 4;     // 14
int y = (2 + 3) * 4;   // 20

Operator * ima veći prioritet od +. Zagrade mijenjaju grupiranje izraza i jasno pokazuju namjeru.

Sažeti prioriteti

  1. Zagrade: ()
  2. Jednočlani operatori: npr. !, ++
  3. Množenje, dijeljenje, ostatak: * / %
  4. Zbrajanje i oduzimanje: + -
  5. Usporedbe i logički operatori: <, ==, &&, ||
  6. Pridruživanje: =
Kada postoji i najmanja dvojba, dodaj zagrade. One su najbrži način da izraz bude čitljiv i nedvosmislen.
4 · Oprez pri evaluaciji

Ne miješaj prioritet s redoslijedom izvođenja

Prioritet govori kako se izraz grupira. Redoslijed kojim se pojedini operandi evaluiraju nije općenito određen za gotovo sve C++ operatore.

Izbjegni sporedne učinke

int i = 1;

// Loša i nejasna ideja:
// int z = i++ + i;

Ne mijenjaj istu varijablu više puta u jednom složenom izrazu. Kod je teško čitljiv i može ovisiti o pravilima evaluacije.

Piši jasnije

int i = 1;
int prvi = i;
i++;
int z = prvi + i;

Više jednostavnih naredbi lakše je provjeriti, objasniti i ispraviti.

5 · Ključna riječ auto

Kompajler zaključuje tip iz početne vrijednosti

Ključna riječ auto omogućuje da se tip varijable zaključi iz inicijalizatora.

Primjeri

auto broj = 42;          // int
auto napon = 230.0;      // double
auto slovo = 'K';        // char
auto aktivan = true;     // bool

auto korijen = std::sqrt(144.0); // double

Važna pravila

  • Varijabla s auto mora imati početnu vrijednost.
  • Tip se određuje pri deklaraciji i kasnije se ne mijenja.
  • auto je posebno koristan kada bi puni tip bio dug i neugledan.
  • Nemoj ga koristiti ako je čitatelju nejasno koji je tip dobiven.
// auto x;  // pogreška: kompajler nema vrijednost iz koje može zaključiti tip
Provjera znanja

Kratko ponavljanje

1. Koji je rezultat izraza?

int x = 10 - 2 * 3;

2. Za što služi const?

Zadatak za vježbu

Napiši program koji učitava duljinu i širinu pravokutnika kao double, definira konstantu const double PDV = 0.25, računa površinu, koristi auto za varijablu rezultata i ispisuje rezultat s dvije decimale. Uključi zaglavlja <iostream> i <iomanip>.

Zapamti: dobar C++ kod koristi odgovarajuće tipove, imenuje nepromjenjive vrijednosti konstantama, oslanja se na standardnu biblioteku i piše izraze bez dvosmislenosti.
