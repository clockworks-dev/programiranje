Učenje · 02 / 16

Ishodi učenja

Nakon ove nastavne jedinice moći ćeš:

  • Razlikovati lokalne i globalne varijable te objasniti njihov doseg i životni vijek u programu.
  • Pravilno koristiti lokalne varijable radi povećanja čitljivosti i sigurnosti programskog koda.
  • Predvidjeti ispis jednostavnog programa i prepoznati uporabu varijable izvan dosega.
Predznanje: deklaracija, inicijalizacija, funkcije i blokovi { }.

Doseg (scope)

Pitanje: Gdje mogu napisati ovo ime?

Životni vijek (lifetime)

Pitanje: Kada varijabla postoji?

Doseg i životni vijek nisu isto. Lokalni doseg ne znači uvijek kratak životni vijek.
Učenje · 04 / 16

Lokalna varijabla

#include <iostream>
void prikaziBodove() {
    int bodovi = 18; // lokalna varijabla
    std::cout << bodovi << '\n';
}
int main() {
    prikaziBodove();
    // std::cout << bodovi; // pogreška: izvan dosega
}
  • Deklarirana je unutar funkcije ili drugog bloka.
  • U ovom primjeru ime je dostupno od deklaracije do kraja funkcijskog bloka.
  • Obična lokalna varijabla nastaje pri izvršavanju deklaracije, životni vijek završava izlaskom iz bloka.
Učenje · 05 / 16

Blok unutar bloka

int main() {
    int broj = 5;
    if (broj > 0) {
        int dvostruko = broj * 2;
        std::cout << dvostruko; // 10
    }
    std::cout << broj; // 5
    // std::cout << dvostruko; // pogreška
}
Unutarnji blok može koristiti varijable iz vanjskog bloka. Ako deklarira vlastitu varijablu istog imena, ona skriva vanjsku varijablu — to nazivamo zasjenjivanje (shadowing). Varijable deklarirane u unutarnjem bloku nisu dostupne izvan tog bloka.

U ovom i kraćim primjerima pretpostavljamo uključen <iostream>.

Učenje · 06 / 16

Svaki poziv, nova varijabla

void broji() {
    int brojac = 0;
    brojac++;
    std::cout << brojac << " ";
}
int main() {
    broji();
    broji();
    broji();
}
Predvidi ispis pa otvori odgovor

Ispis: 1 1 1. Svaki poziv stvara novu običnu lokalnu varijablu i inicijalizira je na 0. Prethodna je prestala postojati.

Učenje · 07 / 16

Globalna varijabla

int ukupno = 0; // izvan svih funkcija
void dodajBodove() {
    ukupno += 5;
}
int main() {
    dodajBodove();
    dodajBodove();
    std::cout << ukupno; // 10
}
  • U primjeru je deklarirana u globalnom prostoru imena.
  • Funkcije nakon deklaracije mogu koristiti njezino ime ako nije zasjenjena (shadowing).
  • Ova globalna varijabla tipa int postoji tijekom izvođenja programa.

„Globalna” ne znači automatski vidljiva u svakoj datoteci: za više izvornih datoteka potrebne su odgovarajuće deklaracije i pravila povezivanja.

Lokalna ili globalna?

Svojstvo Obična lokalna Globalna u primjerima
Mjesto deklaracije Unutar bloka Izvan funkcija, u globalnom prostoru imena
Doseg imena Od deklaracije do kraja bloka, uz pravila zasjenjivanja (shadowing) Nakon deklaracije, uz pravila vidljivosti
Životni vijek Od inicijalizacije do izlaska iz bloka Tijekom izvođenja programa za prikazane int varijable
Novi poziv funkcije Nova varijabla Ista zajednička varijabla
Tipična namjena Privremeni izračuni Zajedničko stanje, samo kada je opravdano
Učenje · 09 / 16

Isto ime, različite varijable

int bodovi = 10;
int main() {
    int bodovi = 3;
    std::cout << bodovi << " ";
    std::cout << ::bodovi;
}
Koji je ispis?

Ispis je 3 10. Lokalno ime zasjenjuje globalno. Operator :: ovdje izričito odabire globalno ime.

Za čitljiviji kod izbjegavaj nepotrebno ponavljanje istih imena u ugniježđenim dosezima.
Za znatiželjne · 10 / 16

Iznimka: lokalna static varijabla

void broji() {
    static int brojac = 0;
    brojac++;
    std::cout << brojac << " ";
}
// Tri poziva funkcije broji() ispisuju: 1 2 3
  • Doseg imena ostaje lokalni: brojac nije dostupan izvan funkcije.
  • Varijabla zadržava vrijednost između poziva.
  • Za ovaj int primjer životni vijek traje od inicijalizacije do završetka programa.
Dodatak: lokalno / globalno opisuje doseg, a automatsko / statičko opisuje trajanje pohrane.
Učenje · 11 / 16

Zašto dati prednost lokalnim?

Čitljivost

Deklaracija je blizu mjesta uporabe. Lakše pratimo odakle vrijednost dolazi.

Manje neželjenih promjena

Funkcija izvan dosega ne može izravno pristupiti toj varijabli po imenu.

Lakše testiranje

Ulaz preko parametara i izlaz preko povratne vrijednosti smanjuju ovisnost o zajedničkom stanju.

Praktična pravila

Inicijaliziraj varijablu, koristi smisleno ime i deklariraj je u najmanjem potrebnom dosegu.

Sigurnost ovdje znači manje programskih pogrešaka, ne potpunu zaštitu programa.

Učenje · 12 / 16

Popravi ovisnost o globalnim

Prije: skrivena ovisnost

int a = 4;
int b = 7;
int rezultat = 0;
void zbroji() {
    rezultat = a + b;
}

Poslije: jasan ulaz i izlaz

int zbroji(int a, int b) {
    int rezultat = a + b;
    return rezultat;
}
int main() {
    int zbroj = zbroji(4, 7);
    std::cout << zbroj; // 11
}

Parametri a i b lokalni su funkciji. Rezultat vraćamo pozivatelju umjesto promjene globalnog stanja.

Vježba · 13 / 16

Praktični zadatak

Napiši program za izračun prosjeka dviju ocjena.

  1. U main() deklariraj i učitaj dvije lokalne varijable tipa int.
  2. Napiši funkciju double prosjek(int prva, int druga).
  3. U funkciji koristi lokalnu varijablu rezultat i vrati je s return.
  4. Ispiši povratnu vrijednost. Ne koristi globalne varijable.
  5. Testiraj ocjene 3 i 4: očekivani rezultat je 3.5.
Prikaži jedno moguće rješenje 
double prosjek(int prva, int druga) {
    double rezultat = (prva + druga) / 2.0;
    return rezultat;
}
int main() {
    int prvaOcjena = 0;
    int drugaOcjena = 0;
    std::cin >> prvaOcjena >> drugaOcjena;
    std::cout << prosjek(prvaOcjena, drugaOcjena);
}

Pretpostavljamo ispravan unos ocjena od 1 do 5. Dijeljenje s 2.0 daje realni rezultat.

Provjera · 14 / 16

Pronađi pogrešku

void pripremi() {
    int temperatura = 22;
}
int main() {
    pripremi();
    std::cout << temperatura;
}
Objašnjenje i popravak

Ime temperatura nije u dosegu funkcije main(). Program se ne može prevesti. Funkcija može vratiti vrijednost, a main() je spremiti u vlastitu lokalnu varijablu.

int pripremi() {
    int temperatura = 22;
    return temperatura;
}
int main() {
    int temperatura = pripremi();
    std::cout << temperatura;
}
